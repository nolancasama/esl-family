ESL Family — Placeholder Art Generator

How to use this tool:
  1. Click Generate All to render all 100 placeholder characters.
  2. Click Download as ZIP to get a zip file containing all 100 PNGs + updated characters.json.
  3. Unzip and place the characters/ folder + characters.json into esl-family/assets/.

To replace placeholders with real art later, simply drop your PNG/WebP files (1024×1024, transparent, full-body) into assets/characters/ with matching filenames (g01.png, i01.png, etc.) and update characters.json "img" fields accordingly.

⚠️ The main app already generates placeholders at runtime — you don't need to run this unless you want to pre-bake the art files.
